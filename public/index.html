    How This Site Works

    • No build step for the frontend: plain HTML/CSS/JavaScript served from the CDN keeps the stack simple.
    • Stateless server: the browser keeps the conversation and sends it with each request, so it scales in a serverless environment.
    • Hand-written agent loop: instead of Gemini's automatic function calling, tool calls and their results are handled explicitly in a loop.
    • LLM calls isolated in one module: the provider is easy to swap, and tests replace it with a mock.
